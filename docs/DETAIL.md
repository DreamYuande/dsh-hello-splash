# Hello 启动动画

默认播放约 3.6 秒。纯白画面写出彩虹渐变的 **Welcome to DSH.**，随后将笔迹收拢为 DSH 官方鲸鱼标志，最后淡出进入主界面。

- 欢迎字用手绘贝塞尔曲线按笔顺逐段绘制，连笔与笔尖移动可见。
- 文字笔迹沿弧线移动到鲸鱼的外轮廓及内部细节。填充沿同一组曲线展开，保留鲸鱼的镂空。
- 播放中可按 Esc 跳过。开启系统减少动态效果时会跳过播放。

**设置 → Welcome splash** 提供自动播放、欢迎文字、背景颜色、动画时长、形变、副标题和 Esc 跳过。可随时点 **预览启动动画**。

插件通过 DSH Next 的启动注入和界面槽位接入。启动数据送达后的加载提示会由纯色覆盖层接替。使用独立的 Windows「DSH Next 白色启动」快捷方式，可以使用 Direct2D 实时绘制默认欢迎动画，让 DSH 同时在后台加载。

插件可通过 DSH 插件管理器停用、卸载或从本地 tarball 安装。配置存于当前 Profile 的 plugin-data/dsh-hello-splash/config.json。备份安装包和配置即可迁移。

适配 DSH Next 2.0.24-next，runtime 0.2.2-rc.5。
